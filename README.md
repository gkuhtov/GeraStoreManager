---

## ✦ Экосистема GeraKStore

```text
GeraKStore
├── Store       • каталог приложений
├── Manager     • управление каталогом
├── Web         • веб-каталог
└── Welcome     • приветственный экран
```

---

## ⚙️ Manager

Manager создан для того, чтобы работа с каталогом была простой и понятной.

- 📱 Добавление приложений
- 🔄 Обновление версий
- 🖼️ Работа с иконками и информацией
- 📂 Поддержание каталога в актуальном состоянии
- ✨ Удобное управление GeraKStore

---

## 💎 Идея

Всё необходимое для управления каталогом постепенно собирается в одном понятном инструменте.
