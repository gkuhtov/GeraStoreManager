## ✦ Что такое GeraStore Manager?

**GeraStore Manager** - это удобный инструмент для управления приложениями в GeraStore.

Он создан для того, чтобы работа с каталогом была максимально простой: добавлять приложения, обновлять информацию и поддерживать GeraStore в порядке.

---

## 📦 Что умеет

- 📱 Добавлять приложения
- 🔄 Обновлять версии
- 🖼️ Работать с иконками и информацией о приложениях
- 📂 Поддерживать каталог GeraStore в актуальном состоянии
- ✨ Упрощать повседневную работу с GeraStore

---

## 💎 Идея

GeraStore Manager появился из простой идеи: **управлять GeraStore должно быть удобно**.

Вместо множества отдельных действий всё необходимое постепенно собирается в одном понятном инструменте.

---

## 🌐 GeraKStore

Manager является частью экосистемы **GeraKStore** и развивается вместе с самим GeraStore.
