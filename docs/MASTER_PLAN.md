# GeraStore Manager

## Описание проекта

GeraStore Manager — программа для управления IPA репозиторием GeraStore.

Цель проекта:

Создать полноценный менеджер для добавления IPA приложений, управления версиями, генерации репозитория и автоматической публикации обновлений.

---

# Текущее состояние проекта

## Уже реализовано

### Управление приложениями

- Добавление IPA файлов.
- Хранение информации о приложениях.
- Хранение нескольких версий.
- Редактирование данных приложения.

### Репозиторий GeraStore

- Генерация repo.json.
- Работа с apps.json.
- Автоматическое обновление данных.
- Публикация через GitHub.
- Автоматический commit и push.

### Поддержка GBox

Поддерживаются поля:

- appName
- appVersion
- appUpdateTime
- appImage
- appPackage
- downloadURL
- size
- appSize
- fileSize
- versions

### Медиа

- Хранение иконок приложений.
- Автоматическое формирование URL иконок.
